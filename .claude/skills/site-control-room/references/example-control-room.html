部署方式
因為沒有終端機，是用 Cloudflare 網頁上的線上編輯器，整份貼上 worker/dashboard-bundle.js 再按 Deploy

常見操作

  1. 後端邏輯有改版 —— 這邊會直接給你新的 dashboard-bundle.js 純文字內容，複製貼到 Worker 編輯器整份取代舊的，按 Deploy。
  2. 要新增密鑰／金鑰（例如之後藍新的 MerchantID）—— Worker 頁面 → Settings → Variables and secrets → Add → 類型選 Secret。存完通常要到 Deployments 頁確認新版本已經是 Active，不然設定不會生效。
  3. 忘記後台密碼（admin.html 登入用）—— 就是 ADMIN_PASSWORD 這個 secret，去上面路徑改掉重存一次即可，改完立刻生效。

核准後要做的事

  1. 跟藍新後台拿 MerchantID、HashKey、HashIV。
  2. 把這三個值加到 Cloudflare Worker 的 Secrets 裡：NEWEBPAY_MERCHANT_ID、NEWEBPAY_HASH_KEY、NEWEBPAY_HASH_IV，再加上 NEWEBPAY_RETURN_URL / NEWEBPAY_NOTIFY_URL。
  3. 不用改任何程式碼——串接邏輯（加解密、簽章驗證）已經寫好在等這幾個值，設定完直接生效。
提醒：這三個金鑰跟後台密碼一樣，只存在 Cloudflare 的 Secrets 裡，不會出現在 GitHub 的任何檔案或這份文件中。
